🌐 Luminous Global Chatbot

A simple and intelligent chatbot project built with Python.
This bot is designed to respond to user messages, handle basic intent recognition, and provide helpful answers.



🚀 Features

🤖 Basic conversational replies

🧠 Simple text-classification / intent handling

🔧 Clean and easy-to-extend code structure

📁 Environment variables supported through .env

📝 Organized project folder for beginners learning AI engineering




📦 Installation

1. Clone the repository

git clone https://github.com/abiodunuthmanmaryam-hub/Luminous-global.git
cd Luminous-global

2. Install dependencies

pip install -r requirements.txt

3. Create your .env file

Inside the project folder, create a file named .env and add your secret keys there:

API_KEY=your_api_key_here

(Remember: this file is hidden using .gitignore and will NOT upload to GitHub.)

4. Run the chatbot

python main.py


🧠 How It Works

The chatbot uses simple logic and text-matching techniques to detect what the user is asking.

The code structure looks like this:

/Luminous-global
 ├─ main.py
 ├─ chatbot.py
 ├─ utils/
 ├─ requirements.txt
 └─ README.md
