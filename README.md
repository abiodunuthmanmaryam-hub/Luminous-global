# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/abiodunuthmanmaryam-hub/Luminous-global.git
```

### Navigate into the project

```bash
cd Luminous-global
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Configure environment variables

Create a `.env` file inside the project directory.

```env
API_KEY=your_api_key_here
```

### Run the chatbot

```bash
python class1.py
```

> **Note:** Replace `class1.py` with the correct entry file if your project uses a different main script.
